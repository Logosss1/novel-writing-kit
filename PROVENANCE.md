# Provenance and Open-Source Record

## Project origin

Novel Writing Kit is a clean, public reorganization of locally supplied writing-skill notes. The public repository contains newly edited, generalized instructions for Chinese novel planning, drafting, continuity checking, prose editing, research, and memory management.

## Deliberate exclusions

- No character sample files are included.
- No private chat transcripts, real-person profiles, or personal identifiers are included.
- No fixed novel setting, numeric system, or genre-specific cast is included.
- No files are copied from the local backup directories into the public repository.

## Adaptation record

The public skills were rewritten to remove project-specific names, private examples, hard-coded story rules, and environment-specific paths. The repository structure, plugin manifest, routing contract, and documentation were prepared for this public project.

# Contributing

Issues and pull requests are welcome. Keep contributions generic enough to support different Chinese novel genres and projects.

Before submitting a change:

1. Do not add private conversations, real-person profiles, or identifying information.
2. Remove hard-coded characters, settings, numeric systems, and local filesystem paths from reusable skills.
3. Keep each skill's trigger conditions, exclusions, inputs, outputs, and recommended next step explicit.
4. Validate JSON and YAML frontmatter, and update `docs/routing.md` when routing changes.
